About Me

I am a software developer focused on building practical applications, strengthening engineering fundamentals and creating user-focused experiences.

My current primary project is SmartPark, a modular parking management simulation platform designed to explore occupancy tracking, dashboard systems, event parking workflows and future AI integrations.

Outside of code I'm drawn to design and how software feels to use which is why I pair every backend project with a frontend goal. I build to learn, and I learn by shipping.

I've been doing photography for around 12 years and have been involved in film and video editing on and off for about 10 years. Both have shaped the way I think about visual design, pacing, and storytelling influences that carry directly into the software I build.

Python | Flask | JavaScript

SmartPark

A full-stack smart parking simulation platform with a real-time web dashboard. Built a multithreaded backend where the parking simulation runs concurrently with a Flask REST API, handling entry, billing, occupancy, and security logging across multiple parking modes.

The live operations dashboard displays occupancy, vehicle analytics, active sessions, revenue, and security events, updating every second via JavaScript fetch polling without a page refresh.

  • Real-Time Web Dashboard
  • Flask REST API
  • Multithreaded Architecture
  • Billing Engine & Analytics
  • OpenCV — v2 Roadmap
